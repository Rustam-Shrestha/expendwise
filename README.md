# ExpendWise

ExpendWise is a personal finance dashboard for tracking transactions, viewing
spending summaries, getting financial advice, and predicting category expenses.
It is split into a React/Vite frontend, an Express/MongoDB API, and a small
FastAPI machine-learning service.

## Features

- Account signup, login, and cookie-based authentication
- Add and review income and expense transactions
- Dashboard spending summaries and charts
- Financial advice based on spending patterns
- Category expense prediction using transaction history and benchmarks
- Risk scoring through the ML service

## Stack

- **Frontend:** React 18, Vite, React Router, Tailwind CSS, Ant Design
- **API:** Node.js, Express, Mongoose, JWT, MongoDB
- **ML service:** Python, FastAPI, scikit-learn, NumPy, Motor

## Requirements

- Node.js 18+ and npm
- Python 3.10+
- MongoDB running locally (default database: `finance`)

## Quick start (Windows)

1. Create the environment file:

   ```bat
   copy .env.example .env
   ```

2. Update `JWT_SECRET` in `.env`. Keep the default `MONGO_URI` if MongoDB is
   running on the local default port.

3. Run the setup script from the repository root:

   ```bat
   setup_and_run.bat
   ```

   The script creates `.venv`, installs dependencies, trains the risk model,
   and opens the frontend, API, and ML service in separate terminals.

4. Open [http://localhost:3000](http://localhost:3000).

For later runs, when dependencies and model artifacts already exist, use:

```bat
run.bat
```

## Manual development

Install dependencies:

```bat
npm install --legacy-peer-deps
cd frontend
npm install
cd ..
.\.venv\Scripts\python.exe -m pip install -r ml\requirements.txt
```

Start each service in a separate terminal:

```bat
# API
node backend\index.js

# ML service
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir ml --host 127.0.0.1 --port 5001

# Frontend
cd frontend
npm run dev
```

The frontend runs on port `3000`, proxies API requests to port `5000`, and
proxies prediction requests to port `5001`.

## Configuration

`.env` is loaded by the backend. Available values include:

| Variable | Default | Purpose |
| --- | --- | --- |
| `PORT` | `5000` | Express API port |
| `MONGO_URI` | `mongodb://127.0.0.1:27017/finance` | MongoDB connection |
| `JWT_SECRET` | none | Secret used to sign auth cookies |
| `SEED_MONTHS` | `12` | Months generated by the seed script |
| `SEED_TRANSACTIONS_PER_MONTH` | `4` | Transactions generated per month |

Never commit `.env` or production secrets.

## API overview

The Express API is available at `http://localhost:5000`:

| Method | Endpoint | Auth |
| --- | --- | --- |
| `GET` | `/healthz` | Public |
| `POST` | `/api/auth/signup` | Public |
| `POST` | `/api/auth/login` | Public |
| `POST` | `/api/auth/logout` | Public |
| `GET` | `/api/gettransaction` | Required |
| `POST` | `/api/addtransaction` | Required |
| `GET` | `/api/financial-advice` | Required |
| `GET` | `/api/cluster-users` | Required |

The ML service is available at `http://localhost:5001`:

- `GET /healthz`
- `POST /predict` or `/api/predict`
- `POST /api/risk/predict`

Authenticated browser requests use the `jwt` cookie. For API calls outside the
frontend, send cookies with the request.

## Database seeding and verification

With `.env` configured and MongoDB running:

```bat
npm run seed
npm run seed -- --force
node backend\scripts\verify_system.js
```

The `--force` option recreates the known demo/application data. Do not use it
against a database containing data you need to preserve.

## Useful commands

| Command | Description |
| --- | --- |
| `npm run dev` | Run the Express API with nodemon |
| `npm run seed` | Seed demo transactions and users |
| `cd frontend && npm run build` | Create a production frontend build |
| `cd frontend && npm run lint` | Run frontend ESLint |
| `python ml\app\training\generate_synthetic.py` | Generate ML training data |
| `python ml\app\training\train_risk.py` | Train the risk model |
